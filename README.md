# ◆ The Corral

A terminal app where **twenty cheap 2024 Meta Llama 3.1 8B instances** (`meta-llama/llama-3.1-8b-instruct`, $0.05/$0.08 per M tokens) sit as **five tables of four**, all talking at once about **one shared seed**, refereed live by **TypeSafe Jev 1.13** — and occasionally **overhearing each other**.

```
uv run corral.py                      # asks for a seed, then runs
uv run corral.py -t "your seed"       # go straight to it (any text: a question, a topic, a sentence)
uv run corral.py -t "..." -n 6        # six rounds then stop
uv run corral.py --headless -t "..."  # no TUI: stream all five chats (scriptable)
uv run corral.py --once               # render one frame and exit (no network)
uv run snapshot.py -t "..." -n 10 -o corral.svg   # a still of a real run (overview + detail)
```

Keys: **1-5** open a table · **o** overview · **Tab/.** cycle · **t** new seed · **space** pause · **s** save · **f** flat · **h** help · **q** quit.

## Two zoom levels

```

┌ the five tables ────────────────────────┐    ┌ Table 4 ──────────────┐┌ the judge ┐
│ Table 1 · on: "the loudness question…"  │    │ full chat, newest at  ││ move,     │
│ Table 2 · on: "what is the wound…"      │    │ the bottom, each line ││ quality,  │
│ Table 3 · on: "a single keen eye…"      │    │ marked ⟪heard⟫ if it  ││ two-ended │
│ Table 4 · on: "layers of a crowd…"      │    │ drifted in from       ││ gauges,   │
│ Table 5 · on: "the surface level…"      │    │ another table         ││ verdict   │
├ the wire · eavesdrops between tables ───┤    └───────────────────────┘└───────────┘
│ T2 ⟶ T4  round 6  Cosmo: "Orson's words…"│
└─────────────────────────────────────────┘
```

* **Every table card** carries its one-sentence summary — **the single most representative line, picked by Jev** (`summary` Choice), not generated by an LLM.
* **The wire** is the eavesdrop map: which table's words reached which, one-way.
* **`⟪heard⟫`** marks a line that drifted in from another table. It lands **verbatim** and the hearing table's next reply must answer it.

## How an eavesdrop works

Between rounds Jev answers, for each table's latest line: *would this carry to a different table?* (`worth` Noul). The best candidate above the gate — **calibrated to 0.46** after measuring that real candidate lines score 0.40–0.53 — is then routed by two more judgements: *which table would overhear it*, and *how should it change that table* (changes what they discuss / adds a new argument / shifts their mood / gets a direct reply / is dismissed). The line lands in the hearing table, marked, and is re-anchored into its reply chain.

A real 10-round run: **3 eavesdrops**, 58 lines, **$0.0117**, 143 Jev calls.

## Jev is the product

Every table, every turn, is **one batched speculative fan-out** answering many judgements over the same state:

| primitive | judgements per table-turn |
| --- | --- |
| **Choice** | who speaks next · which line the reply answers · the one-line **summary** · the table's current **thread** · the line's voice family · its discourse **move** · the **figure** it asserts · the final **outcome** |
| **Noul** | the four gauges (heat / consensus / drift / novelty) · **cohesion** · does the line **assert a checkable claim** · four **stance** probabilities · three **belief-tracking** propositions · the eavesdrop **worth** |
| **Score** | **originality · clarity · insight** per line, normalized and **composited in code** (weights in `room.QUALITY_WEIGHTS`) |

And they drive the app: **confidence-gated routing** (an unsure pick explores a quiet llama), **belief tracking** (three sparklines per table), **cohesion** scored per line, and **one-way eavesdrops** decided by judgement, not a coin flip.

## Design provenance

Every fork went through Jev, including an **adversarial critique of the ask itself**. `jev_verify` confirmed all six of my understanding-claims against your literal words; `jev_classify` then sorted the *underspecified* parts, and the three that genuinely changed the build went back to you (all five tables share **one** seed; this **replaces** the old 20-in-one chat; eavesdrops are **one-way**). Jev also chose the mechanism (`judged_leak_quote`, 0.80) and the summary source (`jev_representative_line`, 0.67), and flagged the two traps: eavesdropping **breaks the reply chain** (guard, 0.98 — hence the ⟪heard⟫ re-anchor) and five tables ≈ **5× the judgement calls** (guard, 1.00 — measured, not assumed).

## Cost

A 10-round run is about **$0.012** — five tables of judging for a little over a cent.

## Layout

| file | what |
| --- | --- |
| `personas.py` | the twenty llamas: sigil, colour, family, voice |
| `room.py` | `Room` (five tables, the wire), `Table` (one conversation), the composite weights, the duplicate guard |
| `judge.py` | the Conductor: the per-table fan-out, the eavesdrop picker, seed screening, verdicts |
| `herd.py` | the llama-3.1-8b writers, strict-JSON replies with repair |
| `session.py` | the round loop: all five tables in parallel, then the eavesdrop check |
| `tui.py` | overview (five cards + the wire) and detail (one table) |
| `corral.py` | entry point, key input, headless mode |
| `snapshot.py` | render a real run to SVG + text |

## A note on the completion gate

`jev_gate` over the raw `judge.py` diff has **escalated** on every revision: it cannot confirm completion claims and scores `correctness` confidence low, while claims are rarely *contradicted* — a known TypeSafe jaggedness on code diffs. The substantive evidence (24 passing tests, live runs, measured leak scores) is what backs the "done" claim here.
